# Case Study: Dictionary Application Using Hash Tables

## 1. Introduction
A dictionary stores words and their meanings. This project uses a Hash Table to store and retrieve words efficiently.

## 2. Objectives
- To store words and meanings.
- To search for words using hashing.
- To handle collisions using Separate Chaining.

## 3. Data Structure Used
A Hash Table is used to store words and meanings. Each word is assigned an index using a hash function.

## 4. Algorithm
1. Create an empty hash table.
2. Calculate the index for the given word using a hash function.
3. Store the word and meaning at that index.
4. If a collision occurs, store multiple entries in the same list using Separate Chaining.
5. Search the word using its calculated index.

## 5. Features
- Add words and meanings.
- Search word meanings.
- Update existing meanings.
- Resolve collisions using Separate Chaining.

## 6. Conclusion
This project explains the use of Hash Tables in a dictionary application. Separate Chaining helps store multiple words when a collision occurs.
