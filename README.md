# Dictionary Application Using Hash Tables

## Introduction
This project implements a simple dictionary application using a hash table in Python.

## Objectives
- To store words and their meanings.
- To search for word meanings quickly.
- To handle hash collisions using Separate Chaining.

## Features
- Add a new word and meaning.
- Search for a word.
- Update an existing word's meaning.
- Handle collisions using lists.

## Data Structure Used
Hash Table with Separate Chaining.

## Technology Used
- Python
- Visual Studio Code
- GitHub

## Conclusion
This project demonstrates how hash tables can store and retrieve dictionary words and meanings efficiently. Separate Chaining is used to resolve collisions.
